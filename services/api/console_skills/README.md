# Reviewed local console skills

`console-evidence` v1 and v2 are original declarative instruction packages defined in `services/api/console.py`. The MIT grant in `LICENSE.MIT` applies to those package manifests and instruction text. No upstream code, graphics, installer, network download, dependency or executable script is included.

Catalog IDs `console-evidence-v1` and `console-evidence` select versions 1 and 2. Both bind stable registry ID `console-evidence`. Updating to v1 is an explicit rollback through the same exact-preview approval. Activation applies to future run snapshots; active runs retain their existing resolved instructions. No tool grants are added by either version.
