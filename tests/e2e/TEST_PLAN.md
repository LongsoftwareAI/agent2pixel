Baseline: requirements v0.1 sections 0–13, API contract v1. The test runner must use a disposable database and workspace root, preserving user data. Provider network tests use local HTTP fixtures, never real credentials. Browser: system `/usr/bin/chromium`, Python Playwright. No new application dependency.

## Visual evidence gate

At 1366×768 capture Home, Office, Agent Studio, Workflow Builder, Furniture editor, Run Monitor/activity, Settings. Capture Office at 1920×1080. Collect pageerror, console.error and failed API calls per screen; assert no app errors. Each screenshot is generated by a real localhost browser, not a reference mockup. Browser tests assert real interactions, refresh persistence and completed output. Screenshot names and test results link in review. Compare with audited Habblaud composition and Pixel Agents readable tile/sprite/state design; explain original-art differences without copied assets.

## Independent review gate

Review application source read-only after implementer handoff; pin exact commit(s). Findings include severity, file:line, reproduction, expected/actual, proposed fix. Application approval requires executed tests and all required P0 evidence. QA test author cannot claim independent approval for own tests; Integrator reviews test contribution. Failed/skipped checks remain explicit.
