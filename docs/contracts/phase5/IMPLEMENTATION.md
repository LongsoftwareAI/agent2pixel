- GET `/api/console/overview?workspace_id` -> `{agents:{total,busy},work:{total,pending_review,completed},runs:{total,active},usage:{input_tokens,output_tokens,actual_cost:null,estimated_cost:null},activity:[],services:[],observed_at}`; additional fields may be additive. Counts based actual records, no fake gateway count.
- GET/POST `/api/console/conversations[?workspace_id]`; POST `{workspace_id,agent_id:null|string,title:string}` -> conversation `{id,workspace_id,agent_id,title,created_at}`; GET list -> array.
- GET `/api/console/conversations/{id}` -> conversation plus `messages:[]`. POST `/api/console/conversations/{id}/messages` `{content,client_request_id,workflow_id?,attachment_ids?:[]}` -> `{message,run_id,work_item_id}`. Require bounded content and idempotency key scoped conversation, same-key changed payload409. Choose explicit workflow or construct one-agent workflow for selected agent; room requires selected configured agent/workflow, never infer permissions from text. Create real work item/run via existing start_run/app runtime; record immutable revision context. Response messages reconcile actual run/task outputs; no fabricated AI response. Existing `/api/runs/{id}/cancel` remains cancellation route if supported (verify actual existing route).
- GET `/api/console/sessions?workspace_id` -> array of run-derived sessions (stable run IDs, agent IDs, state/start/end, conversation_id?). Existing run detail contains task outputs/events.
- GET `/api/console/inbox?workspace_id` -> array of discriminated `{id,kind,run_id?,work_item_id?,...}` entries from pending approvals/gates and work acceptance; existing decision APIs perform mutation.
- GET `/api/console/health?workspace_id` -> `{items:[{id,name,kind,state,reason,observed_at,...}],observed_at}`; secret presence/names only. GET `/api/console/topology?workspace_id` -> `{nodes:[{id,label,kind,state,...}],edges:[{source,target,...}],observed_at}` read-only actual registry/run sources.
- GET `/api/console/usage?workspace_id&period=7|30|90|all` -> `{daily:[],by_agent:[],by_model:[],totals:{input_tokens,output_tokens,requests,actual_cost:null,estimated_cost:null},pricing:[],observed_at}`; missingusage distinguish unknown vs0. No raw video values.
- GET `/api/console/schedules?workspace_id` -> `{items:[],capability:{state,reason},observed_at}`; monitor only, no scheduler mutation. Observations persisted by reviewed local adapter, not fabricated jobs.
- GET/PATCH `/api/console/agents/{id}/soul` -> `{agent_id,content,revision,updated_at}`; PATCH `{content,revision}` conflict409; bind future system prompt only, active run snapshot unchanged; audit change.
- GET `/api/console/skills?workspace_id&agent_id?` -> `{packages:[],bindings:[]}`. POST `/api/console/agents/{id}/skills/preview` `{package_id,operation:'install'|'update'|'remove'}` -> `{approval_id,manifest,diff,...}`; POST `/api/console/agents/{id}/skills/apply` `{approval_id}` applies exact reviewed payload once, conflict on changed/current version. Package manifest `{id,version,sha256,license,description,dependencies,tool_grants}`; local reviewed declarative package only, cannot silently elevate grants. Rollback/activation state recorded, no arbitrary URL/installscript. Backend publishes exact catalog and activation semantics in handoff before FE integration.
- GET/PATCH `/api/console/preferences?workspace_id` -> settings object; PATCH validates theme light/dark/system, accent blue/black, sidebar full/collapsed, font small/medium/large, density comfortable/compact, office_enabled boolean, start_page known route, refresh fast/slow/off; persistence and versioning. Local prepaint preference may cache, server authoritative.
- GET `/api/console/logs?workspace_id&kind=system|audit&limit=100&before?` -> `{items:[],next_cursor:null|string}`; scope/cursors bounded, redacted, no env/prompt dump. Existing audit can supply source but distinguish diagnostics/actions.
- POST `/api/console/attachments` JSON `{workspace_id,name,media_type,content}` UTF8 text/CSV/Markdown only at first, max1MiB; -> `{id,name,media_type,size,sha256,...}` stored as source-backed attachment after containment checks; reject unsupported formats explicitly. Image/audio formats require actual validated adapter before claiming support.
- GET `/api/console/capabilities?workspace_id` -> capability map including STT. Voice adapter unconfigured if missing; UI cannot invent transcript. Backend may add browser-submitted transcript draft route only with explicit capability decision; live STT remains OPEN unless actually tested.
